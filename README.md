# Data Pipeline Practice

A small data pipeline built with Python and pandas.

## What it does
1. Extract: reads sales data from sales.csv
2. Transform: adds a new column with the price including 10% tax
3. Load: saves the result to clean_sales.csv

## Files
- sales.csv: the original data
- read_data.py: the Python code
- clean_sales.csv: the final cleaned data

## Tools used
Python, pandas, GitHub
